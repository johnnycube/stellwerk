Silences cannot be changed on this node.

A silence mutes matching events for a while, e.g. during maintenance. They still show up in the audit log as silenced. Match on source=, status= or any label, e.g. source=k8s* severity=warning. A heartbeat alarm is muted with heartbeat=<name>.
